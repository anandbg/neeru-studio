# Neeru Studio

A drawing and spreadsheet app with AI built in. It runs in the browser.

- **Design:** pen, line, rectangle, ellipse, star, polygon and custom shapes, plus a move tool, colour wheel, swatches, eyedropper, undo and PNG export.
- **Sheet:** a grid with formulas (`=SUM(B2:B6)`, `AVERAGE`, `MIN`, `MAX`, `COUNT`).
- **Ask AI:** type "draw a sunset over the sea" or "make a pocket-money table".
  - It uses OpenRouter's free models.
  - Bring your own free key from openrouter.ai/keys and paste it into ⚙︎.
  - The key is saved only in your browser.
- **Voice:** tap 🎤 and speak. Works in Chrome, Edge and Safari.

All code is original.
